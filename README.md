# make-knowledge-cards

一个将文章转成知识卡片的开源 Codex Skill：从用户粘贴的内容或本地 Markdown/TXT 文件中，提炼出真正重要、彼此不重复的知识点，并以便于复习的卡片形式输出。目标是 “有用的回顾”，而非面面俱到的摘要。

## 项目解决什么问题

阅读长文章时，信息密集、重点分散，难以快速抓住并记住核心内容。本项目把任意一篇文章自动蒸馏成一小套互不重复、忠于原文的复习卡片，让学习者不必反复通读全文，即可按卡片逐点复习和自测，提高记忆效率。

## 主要功能



* **输入形式**：接受用户粘贴的文章文本，或本地的 `.md`、`.markdown`、`.txt` 文件；读取本地文件后再制作卡片。

* **要点提炼**：识别文章的核心论点、概念、方法、区分点与限定条件，优先选取理解或应用材料所必需的知识点。

* **去重压缩**：合并重复表述与重叠观点，剔除装饰性细节、离题内容和缺乏支撑的旁述。

* **一卡一点**：每张卡片只承载一个知识点；合并了独立观点的卡片会被拆分，重复同一观点的卡片会被合并。

* **忠于原文**：保留原文中的限定语、不确定性及适用范围；原文信息不足时如实说明或省略，不凭空补写。

* **卡片数量**：原文有足够多的独立重要知识点时生成 5～8 张；不足时生成更少，不为凑数而注水。

* **标准卡片结构**：每张卡片含「核心知识 / 简明解释 / 例子或自测问题」，便于主动回忆。

* **语言与格式**：按用户语言输出，使用带编号章节的 Markdown。

## 安装方法



1. 将本仓库中的 `skills/make-knowledge-cards` 目录（含 `SKILL.md` 与 `agents/openai.yaml`）复制到 Codex 可发现 Skills 的目录：

* 项目级：放在项目的 Skills 目录中（如 `.codex/skills/`），仅当前项目可用；

* 用户级：放在用户全局的 Skills 目录中（如 `~/.codex/skills/`），所有项目可用。

1. 以最终目录名为 `make-knowledge-cards` 存放，确保 Skill 能按名字被发现。

2. 重新启动或刷新 Codex 会话，使新 Skill 生效。

## 使用方法

安装后，直接让 agent 调用该 Skill，方式为把文章内容粘贴进来，或提供本地文件路径：



```
使用 $make-knowledge-cards 把下面的文章做成知识卡片：
……文章内容……
```

也可以提供本地文件路径：



```
使用 $make-knowledge-cards 将 E:\notes\learning.md 转成知识卡片。
```

Skill 通常生成 5～8 张卡片；当原文的独立重要知识不足时会生成更少，不会为了凑数而补充原文没有的信息。

## 输入与输出示例

输入：



```
番茄工作法将工作拆成 25 分钟专注时段，每个时段后短暂休息。
完成四个时段后，安排一次较长休息。其重点是减少分心并建立可持续节奏。
```

输出：



```
## 1. 用固定专注时段组织工作

**核心知识：** 番茄工作法将工作拆成 25 分钟的专注时段。

**简明解释：** 固定时段让任务有清晰的开始与结束，帮助把注意力集中在当前工作上。

**例子或自测问题：** 自测：一个番茄钟的专注时长是多少？

## 2. 休息是节奏的一部分

**核心知识：** 每个专注时段后短暂休息，完成四个时段后安排较长休息。

**简明解释：** 该方法把休息与专注交替安排，以维持可持续的工作节奏。

**例子或自测问题：** 自测：完成四个专注时段后应如何安排？
```

## 范围

目前仅支持粘贴文本和本地 `.md`、`.markdown`、`.txt` 文件；不支持网页抓取、PDF、Anki 导出或图形界面。若用户实际提供了其他文本承载格式（如带正文的文档），需先经文档读取工具抽取正文后再调用本 Skill。
